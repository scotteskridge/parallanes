# Weigh the plan process against the size of the code

About 60 logged decisions, plans with ten open questions and several review rounds each, for about
3,500 lines of source. That shows rigour, but some readers will see ceremony, and it slows
delivery. Splitting plan 07 into 07 and 07b was a step this way. An owner's call, not a code change.

**Done when:** the owner has decided whether to change anything (for example a cap on open
questions per plan, or one review round by default for small plans), and the outcome is in the
decisions log.
